4.14. Dashboard 3: Marketing Performance

The Marketing Performance dashboard is used to evaluate the effectiveness of traffic sources and marketing campaigns.

This dashboard helps answer the following questions:

  • Which traffic source generates the most views, clicks, add-to-carts, and purchases?

  • Which traffic source has the best conversion rate?

  • Which traffic source has a high bounce rate?

  • Which campaign generates the most purchases?

  • Which campaign has good conversion but low bounce rate?

Views used:

  • vw_traffic_source_performance

  • vw_campaign_performance

I. CREATE TIME FILTERS

Because the views use the event_date column, create the following calculated fields:

  • event_year
  • event_quarter
  • event_month

The formulas are similar to Dashboard 2:

  • event_year = extract('YYYY', {event_date})
  • event_quarter = floor((extract('MM', {event_date}) - 1) / 3) + 1
  • event_month = extract('MM', {event_date})

Then create filter controls for the dashboard.

II. CREATE KPI CARDS

KPI 1: TOTAL EVENTS

Create the Total Events KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: total_events(Sum)
  • Title: TOTAL EVENTS

Insight: Shows the total number of events generated by marketing activities. This is used to evaluate the overall traffic/interactions from marketing channels.

KPI 2: TOTAL VIEWS

Create the Total Views KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: views(Sum)
  • Title: TOTAL VIEWS

Insight: Shows the total number of views from marketing sources. If views are high but conversion is low, traffic volume is high but traffic quality may not be good.

KPI 3: TOTAL CLICKS

Create the Total Clicks KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: clicks(Sum)
  • Title: TOTAL CLICKS

Insight: Shows how much users interact after seeing the product or marketing content.

KPI 4: TOTAL ADD TO CARTS

Create the Total Add to Carts KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: add_to_carts(Sum)
  • Title: TOTAL ADD TO CARTS

Insight: Shows whether marketing can bring users to the purchase-intent stage.

KPI 5: TOTAL PURCHASES

Create the Total Purchases KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: purchases(Sum)
  • Title: TOTAL PURCHASES

Insight: Shows the total number of purchases generated by marketing activities.

KPI 6: BOUNCE RATE

Create the Bounce Rate KPI Card with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: KPI
  • Value: bounce_rate(Average)
  • Format: Percentage
  • Title: BOUNCE RATE

Insight: Shows the overall quality of traffic. A high bounce rate means users enter but leave quickly, which may be caused by the wrong target audience or an ineffective landing page.

I. CREATE MARKETING FUNNEL VOLUME BY TRAFFIC SOURCE VERTICAL BAR CHART

This visual is used to compare funnel volume by traffic source.

Create the Marketing Funnel Volume by Traffic Source chart with the following configuration:

  • View: vw_traffic_source_performance

  • Visual type: Vertical bar chart

  • X-axis: traffic_source

  • Value:

    • views(Sum)
    • clicks(Sum)
    • add_to_carts(Sum)
    • purchases(Sum)

  • Sort: purchases Descending

  • Title: MARKETING FUNNEL VOLUME BY TRAFFIC SOURCE

Insight: This chart shows how many views, clicks, add-to-carts, and purchases each traffic source generates. It can be used to detect which channel brings in high traffic but does not generate corresponding purchases.

II. CREATE TRAFFIC SOURCE QUALITY VERTICAL BAR CHART

This visual is used to compare traffic quality between sources.

Create the Traffic Source Quality chart with the following configuration:

  • View: vw_traffic_source_performance

  • Visual type: Vertical Bar chart

  • X-axis: traffic_source

  • Value:

    • view_to_purchase_rate(Average)
    • bounce_rate(Average)

  • Format: Percentage

  • Sort: view_to_purchase_rate Descending

  • Title: TRAFFIC SOURCE QUALITY

Insight: A good traffic source is one with a high view_to_purchase_rate and a low bounce_rate. For example, if Email has high conversion and low bounce, it is a high-quality traffic source. If Social brings a lot of traffic but has a high bounce rate, the target audience or ad content should be reviewed.

III. CREATE PURCHASE TREND BY TRAFFIC SOURCE LINE CHART

Create the Purchase Trend by Traffic Source chart with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: Line chart
  • X-axis: event_date
  • Value: purchases(Sum)
  • Color/Group: traffic_source
  • Title: PURCHASE TREND BY TRAFFIC SOURCE

Insight: This chart shows how purchases from each traffic source change over time. It can be used to identify which source is growing well, which source is becoming less effective, or when purchase spikes occur due to campaigns or promotions.

IV. CREATE CONVERSION RATE TREND BY TRAFFIC SOURCE LINE CHART

Create the Conversion Rate Trend by Traffic Source chart with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: Line chart
  • X-axis: event_date
  • Value: view_to_purchase_rate(Average)
  • Color/Group: traffic_source
  • Format: Percentage
  • Title: CONVERSION RATE TREND BY TRAFFIC SOURCE

Insight: This chart shows the conversion effectiveness of each traffic source over time. If purchases increase but the conversion rate decreases, the source may be bringing more traffic but with lower traffic quality.

V. CREATE BOUNCE RATE TREND BY TRAFFIC SOURCE LINE CHART

Create the Bounce Rate Trend by Traffic Source chart with the following configuration:

  • View: vw_traffic_source_performance
  • Visual type: Line chart
  • X-axis: event_date
  • Value: bounce_rate(Average)
  • Color/Group: traffic_source
  • Format: Percentage
  • Title: BOUNCE RATE TREND BY TRAFFIC SOURCE

Insight: This chart shows which traffic source has an increasing or decreasing bounce rate over time. If the bounce rate suddenly increases for a source, a new campaign may be attracting the wrong audience or the landing page may have issues.

VI. CREATE TOP CAMPAIGNS BY PURCHASES HORIZONTAL BAR CHART

Create the Top Campaigns by Purchases chart with the following configuration:

  • View: vw_campaign_performance
  • Visual type: Horizontal bar chart
  • Y-axis: campaign_id
  • Value: purchases(Sum)
  • Sort: purchases Descending
  • Title: TOP CAMPAIGNS BY PURCHASES

Insight: This chart shows which campaign generates the most purchases. It is an important chart for identifying which campaign contributes the most to marketing results.

VII. CREATE CAMPAIGN CONVERSION VS BOUNCE RATE CLUSTERED BAR COMBO CHART

Create the Campaign Conversion vs Bounce Rate chart with the following configuration:

  • View: vw_campaign_performance

  • Visual type: Clustered bar combo chart

  • X-axis: campaign_id

  • Value:

    • conversion_rate(Average)
    • bounce_rate(Average)

  • Format: Percentage

  • Title: CAMPAIGN CONVERSION VS BOUNCE RATE

Insight: This chart helps evaluate campaign quality. A good campaign has a high conversion rate and a low bounce rate. If a campaign has high purchases but also a high bounce rate, it may generate volume but the traffic quality is not yet optimized.

VIII. CREATE CAMPAIGN FUNNEL VOLUME VERTICAL STACKED BAR CHART

Create the Campaign Funnel Volume chart with the following configuration:

  • View: vw_campaign_performance

  • Visual type: Vertical stacked bar chart

  • X-axis: campaign_id

  • Value:

    • views(Sum)
    • clicks(Sum)
    • add_to_carts(Sum)
    • purchases(Sum)

  • Sort: purchases Descending

  • Title: CAMPAIGN FUNNEL VOLUME

Insight: This chart shows the volume generated by each campaign at every funnel step. It can be used to identify campaigns with many views but few purchases, or campaigns with low views but good conversion.

IX. CREATE CAMPAIGN CONVERSION RATE TREND LINE CHART

Create the Campaign Conversion Rate Trend chart with the following configuration:

  • View: vw_campaign_performance
  • Visual type: Line chart
  • X-axis: event_date
  • Value: conversion_rate(Average)
  • Color/Group: campaign_id
  • Format: Percentage
  • Title: CAMPAIGN CONVERSION RATE TREND

Insight: This chart shows how the conversion rate of each campaign changes over time. If a campaign’s conversion rate drops after a few days, the audience may be saturated or the ad content may have become less effective.
