XỬ LÝ PREPROCESSING CHO DATASET Ở LOCAL

I. Explorer dataset:

  • Link: https://www.kaggle.com/datasets/geethasagarbonthu/marketing-and-e-commerce-analytics-dataset
  • Dataset được sinh từ Python, sử dụng 3 files: events.csv, products.csv, transactions.csv

events.csv (2,000,000 records)

  • Large fact table chứa tương tác người dùng: views, clicks, add-to-cart, bounces, purchases.
  • Bao gồm metadata như device_type, traffic_source, page_category, session_duration_sec.
  • campaign_id và experiment_group hỗ trợ phân tích uplift và A/B testing.
  • Có tính nhiễu thực tế: thiếu giá trị device type, traffic source viết hoa/viết thường không nhất quán.
  • Khóa chính event_id, có foreign key tới customers, products và campaigns.

Data columns:

# column dtype Non-null Mô tả
0 event_id int64 X
1 timestamp str X 01-01-2021 -> 31-12-2023, template: yyyy/mm/dd hh:mm
2 customer_id int64 X
3 session_id int64 X
4 event_type str X view: 1,043,573, click: 379,008, add_to_cart: 284,370, bounce: 189,922, purchase: 103,127
5 product_id float64 Thiếu 200,371
6 device_type str Thiếu 40,300 mobile: 1,176,146, desktop: 685,433, tablet: 98,121; NaN -> fill bằng unknow
7 traffic_source str X Organic: 776,758, Paid Search: 387,657, Social: 291,194, Email: 290,651, Direct: 193,870; còn có ORGANIC, PAID SEARCH, SOCIAL, EMAIL, DIRECT
8 campaign_id int64 X
9 page_category str X PLP: 601,284, PDP: 599,638, Home: 399,723, Checkout: 199,871, Cart: 199,484
10 session_duration_sec float64 X
11 experiment_group str X Control: 1,198,404, Variant_A: 401,413, Variant_B: 400,183

products.csv (2,000 records)

  • Một hàng tương ứng mỗi sản phẩm trong catalog, kèm category và brand metadata.
  • base_price phân bổ theo nhóm giá thực tế.
  • Có thông tin thời điểm ra mắt sản phẩm để phân tích lifecycle.
  • is_premium xác định các sản phẩm phân khúc cao cấp.
  • Khóa chính product_id nối tới events và transactions.

Data columns:

# column dtype Non-null Mô tả
0 product_id int64 X
1 category str X Electronics: 455, Fashion: 418, Home: 396, Grocery: 312, Sports: 218, Beauty: 201
2 brand str X Brand_1 -> Brand_100
3 base_price float64 X
4 launch_date str X yyyy/mm/dd
5 is_premium int64 X 0 hoặc 1

transactions.csv (103,127 records)

  • Mỗi hàng tương ứng một giao dịch mua hoàn thành.
  • Bao gồm số lượng, chiết khấu, và tổng doanh thu thô (refund có giá trị âm).
  • Liên kết trực tiếp với sự kiện purchase qua timestamp, customer_id, và product_id.
  • Hỗ trợ phân tích doanh thu, hành vi refund và hiệu quả chiến dịch.
  • Khóa chính transaction_id, tham chiếu tới customers, products và campaigns.

Data columns:

# column dtype Not-null Mô tả
0 transaction_id int64 X
1 timestamp str X yyyy/mm/dd
2 customer_id int64 X
3 product_id float64 Thiếu 10,449 Đưa vào error/quarantine hoặc giữ với flag lỗi
4 quantity int64 X 1: 77,352; 2: 15,327; 3: 7,324; 4: 3,124
5 discount_applied float64 X 0.0: 61,923; 0.05: 15,473; 0.1: 12,370; 0.15: 8,311; 0.2: 5,050
6 gross_revenue float64 Thiếu 10,449 Có 2,704 giá trị âm (refund)
7 campaign_id int64 X
8 refund_flag int64 X 0: 100,098; 1: 3,029 (gross_revenue âm hoặc null)
