The **Marketing Performance** dashboard is used to evaluate the effectiveness of traffic sources and marketing campaigns.

**This dashboard helps answer the following questions:**

* Which traffic source generates the most views, clicks, add-to-carts, and purchases?

* Which traffic source has the best conversion rate?

* Which traffic source has a high bounce rate?

* Which campaign generates the most purchases?

* Which campaign has good conversion but low bounce rate?

**Views used:**

* vw_traffic_source_performance

* vw_campaign_performance

### I. CREATE TIME FILTERS

Because the views use the **event_date** column, create the following calculated fields:

* event_year
* event_quarter
* event_month

The formulas are similar to Dashboard 2:

* **event_year** = `extract('YYYY', {event_date})`
* **event_quarter** = `floor((extract('MM', {event_date}) - 1) / 3) + 1`
* **event_month** = `extract('MM', {event_date})`

Then create filter controls for the dashboard.

#### I. CREATE MARKETING FUNNEL VOLUME BY TRAFFIC SOURCE VERTICAL BAR CHART

This visual is used to compare funnel volume by traffic source.

Create the Marketing Funnel Volume by Traffic Source chart with the following configuration:

* View: **vw_traffic_source_performance**
* Visual type: **Vertical bar chart**
* X-axis: **traffic_source**
* Value:

  * **views(Sum)**
  * **clicks(Sum)**
  * **add_to_carts(Sum)**
  * **purchases(Sum)**
* Sort: **purchases Descending**
* Title: **MARKETING FUNNEL VOLUME BY TRAFFIC SOURCE**

![](/images/4-Workshop/4.14-Dashboard-3-Marketing-Performance/image-007.png)

**Insight**:
This chart shows how many views, clicks, add-to-carts, and purchases each traffic source generates. It can be used to detect which channel brings in high traffic but does not generate corresponding purchases.

#### II. CREATE TRAFFIC SOURCE QUALITY VERTICAL BAR CHART

This visual is used to compare traffic quality between sources.

Create the Traffic Source Quality chart with the following configuration:

* View: **vw_traffic_source_performance**
* Visual type: **Vertical Bar chart**
* X-axis: **traffic_source**
* Value:

  * **view_to_purchase_rate(Average)**
  * **bounce_rate(Average)**
* Format: **Percentage**
* Sort: **view_to_purchase_rate Descending**
* Title: **TRAFFIC SOURCE QUALITY**

![](/images/4-Workshop/4.14-Dashboard-3-Marketing-Performance/image-008.png)

**Insight**:
A good traffic source is one with a high view_to_purchase_rate and a low bounce_rate. For example, if Email has high conversion and low bounce, it is a high-quality traffic source. If Social brings a lot of traffic but has a high bounce rate, the target audience or ad content should be reviewed.
