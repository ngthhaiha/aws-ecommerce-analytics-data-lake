The **Product Analytics** dashboard is used to evaluate sales performance by product, category, brand, and premium/non-premium product groups.

**This dashboard helps answer the following questions:**

* Which products generate the most revenue?

* Which category performs best?

* Which brand has the highest performance?

* Do premium products generate strong revenue?

* Which products or categories have a high refund rate?

View used: **vw_product_revenue**.

### I. CREATE TIME FILTERS

Create the following calculated fields:

* **transaction_year** = `extract('YYYY', {transaction_date})`
* **transaction_quarter** = `floor((extract('MM', {transaction_date}) - 1) / 3) + 1`
* **transaction_month** = `extract('MM', {transaction_date})`

Then create filter controls similar to Dashboard 1.

### II. CREATE KPI CARDS

#### KPI 1: TOTAL REVENUE

Create the Total Revenue KPI Card with the following configuration:

* View: **vw_product_revenue**
* Visual type: **KPI**
* Value: **total_revenue(Sum)**
* Format: **Currency**
* Title: **TOTAL REVENUE**

![](/images/5-Workshop/5.15-Dashboard-4-Product-Analytics/image-001.png)

Shows the total revenue generated from products. This is the most important overview metric in Product Analytics.

* View: **vw_product_revenue**

* X-axis: **transaction_date**
* Value: **total_revenue(Sum)**

This chart shows how product revenue changes over time. By looking at the chart, viewers can identify which days or months have revenue increases, decreases, or abnormal spikes.

#### II. CREATE PRODUCT SALES TREND LINE CHART

Create the Product Sales Trend chart with the following configuration:

* View: **vw_product_revenue**
* Visual type: **Line chart**
* X-axis: **transaction_date**
* Value: **total_units_sold(Sum)**
* Title: **PRODUCT SALES TREND**

![](/images/5-Workshop/5.15-Dashboard-4-Product-Analytics/image-008.png)

#### III. CREATE PRODUCT PERFORMANCE BY CATEGORY COMBO CHART

Create the Product Performance by Category chart with the following configuration:

* View: **vw_product_revenue**
* Visual type: **Combo chart**
* X-axis: **category**
* Bar value: **total_revenue(Sum)**
* Line value: **total_units_sold(Sum)**
* Sort: **total_revenue Descending**
* Title: **PRODUCT PERFORMANCE BY CATEGORY**

![](/images/5-Workshop/5.15-Dashboard-4-Product-Analytics/image-009.png)

**Insight**:
This chart shows which category generates high revenue and which category sells many units. If a category has high units sold but low revenue, it may be a low-price product group. If revenue is high but units sold are low, it may be a high-value product group.

#### V. CREATE PREMIUM VS NON-PREMIUM REVENUE BAR CHART

Create the Premium vs Non-Premium Revenue chart with the following configuration:

* View: **vw_product_revenue**
* Visual type: **Bar chart**
* X-axis: **is_premium**
* Value: **total_revenue(Sum)**
* Sort: **total_revenue Descending**
* Title: **PREMIUM VS NON-PREMIUM REVENUE**

Create the Premium vs Non-Premium Sales Volume chart with the following configuration:

* View: **vw_product_revenue**
* Visual type: **Grouped bar chart**
* X-axis: **is_premium**
* Value:

  * **total_transactions(Sum)**
  * **total_units_sold(Sum)**
* Title: **PREMIUM VS NON-PREMIUM SALES VOLUME**

![](/images/5-Workshop/5.15-Dashboard-4-Product-Analytics/image-012.png)

**Insight**:
This chart shows whether the premium or non-premium group has better sales volume. If non-premium products have higher transactions/units but revenue does not exceed premium revenue by much, this means the group sells more but has lower value. If premium products sell fewer units but generate higher revenue, this means premium products have better order value.
